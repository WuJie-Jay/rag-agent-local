# 本地化 RAG 智能知识库 Agent 系统

## 项目简介
本项目是一套**全本地化部署的检索增强生成（RAG）+ 智能体（Agent）问答系统**，基于开源大模型与向量数据库实现私有知识库的快速构建与智能问答。系统全程离线运行，数据无需上传第三方服务，在保障数据隐私的同时，支持多工具自主调度的复杂任务处理。

项目采用模块化架构设计，覆盖文档处理、向量存储、语义检索、提示词工程、ReAct 智能体调度等完整 AI 应用开发核心链路，可作为企业内部知识库、智能问答助手的基础原型。

## 核心功能
### 1. 私有知识库构建
- 支持 Markdown、TXT、PDF 等多格式文档一键入库
- 内置文本清洗、递归字符分块、语义重叠优化等预处理能力
- 向量数据持久化存储，支持多知识库集合隔离管理
- 可灵活配置分块大小、重叠区间等核心参数

### 2. 基础 RAG 精准问答
- 基于语义相似度的向量检索，精准召回相关文档片段
- 结构化提示词工程，内置多层防幻觉约束机制
- 严格限定回答边界，资料外内容明确兜底，降低幻觉输出
- 支持原文溯源，答案可对应到具体文档片段

### 3. ReAct 智能体（Agent）对话
- 基于 ReAct 范式实现多轮思考-行动循环，支持复杂多步任务
- 内置知识库问答、数学计算器等工具，模型自主判断调用时机
- 最大步数限制与异常兜底，防止死循环与格式解析错误
- 工具化扩展架构，可快速接入新增业务工具

## 快速开始
### 1. 环境要求
- Python 3.10 及以上版本
- 已安装 Ollama 并可正常运行
- 建议显存 ≥ 6GB（运行 7B 量化模型）

### 2. 前置准备
1. 拉取所需大模型与嵌入模型
```bash
ollama pull qwen2.5:7b
ollama pull nomic-embed-text
```

2. 克隆项目到本地
```bash
git clone [https://github.com/](https://github.com/)你的GitHub用户名/你的仓库名.git
cd 你的仓库名
```

### 3. 安装依赖
```bash
pip install langchain langchain-core langchain-text-splitters langchain-chroma langchain-ollama pymupdf
```

### 4. 启动项目
```bash
python app.py
```
启动后根据命令行菜单选择对应功能即可使用。

## 使用指南
### 功能1：构建知识库
1. 选择菜单「1. 构建知识库」
2. 输入本地文档路径（支持相对/绝对路径）
3. 指定知识库集合名，系统自动完成加载、分块、向量化、持久化全流程

### 功能2：基础 RAG 问答
1. 选择菜单「2. 基础 RAG 问答」
2. 选择目标知识库集合
3. 输入问题即可获取基于知识库的精准回答
4. 输入 `exit` 返回主菜单

### 功能3：Agent 智能对话
1. 选择菜单「3. Agent 智能对话」
2. 输入问题，系统自主判断是否调用工具、调用哪个工具
3. 支持多步骤复杂任务，如「查询RAG有几个优势，数量乘以10是多少」
4. 输入 `exit` 返回主菜单

## 核心技术亮点
1. **全链路本地化隐私保护**：从模型推理到向量存储全程离线运行，数据无需出本地，适配涉密、敏感知识库场景。
2. **ReAct 范式多工具调度**：自主实现思考-行动-观察循环，模型可根据任务复杂度自主决策工具调用，支持多步串联任务。
3. **多层级防幻觉体系**：从检索层（相似度阈值过滤）、提示词层（强边界约束）、结果层（无结果兜底）三层抑制幻觉输出，提升回答可靠性。
4. **模块化可扩展架构**：工具、文档加载器、分块策略均为独立模块，新增能力无需改动核心逻辑，便于快速迭代。
5. **工程化异常兜底**：内置参数清洗、格式容错、最大步数限制、异常捕获等机制，保障系统运行稳定性。

## 常见问题
### Q: 知识库构建后查询全部返回「未提及相关内容」
A：优先检查向量库路径与集合名是否一致；建库与查询需使用相同的嵌入模型；可删除 `chroma_db` 目录后重建向量库。

### Q: Agent 不调用工具，直接自行回答
A：优化工具描述的适用场景；调低模型 `temperature` 至 0.0；在系统提示词中强化「RAG 专业问题必须调用工具」的约束。

### Q: 检索效果差，相关内容排不到前面
A：调大分块大小（推荐 800 字符）与重叠区间，增强单块语义密度；适当扩大召回 `top_k` 数量；避免重复数据入库。
